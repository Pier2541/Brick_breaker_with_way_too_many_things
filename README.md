# Brick_breaker_with_way_too_many_things
This is my terra project, a brick breaker variant with a lot of stages (hopefully).
It works on both mobile and pc, but it’s better to play it on PC.
Only needs a mouse to control and a keyboard. Still updating it lot.

To run it, run the HTML file here on github (it will be updated with every major upgrade i make to the game, such as new stages etc.) or, if you want the current most updated version, go on https://scratch.mit.edu/projects/1393225156

I’ve made this project as a commit for Terra, an Hack Club coding initiative, and it’s hopefully goint to be the project that will take me to the end.
